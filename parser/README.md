# Parser

Сервис на Telethon читает новые сообщения из `CHAT_ID` и публикует в RabbitMQ JSON:
`chat_id`, `message_id`, `date`, `text`, `entities`. Передаются исходный текст и оформление
в формате Telegram Bot API. Медиа не скачиваются, подписи передаются как текст с оформлением.
Редактирование, удаление сообщений и история за время остановки не обрабатываются.
При ошибке публикации автоматической повторной отправки поста пока нет.

Настройки общие для проекта — в корневом `.env`.
Инструкция сборки, авторизации и запуска: [README проекта](../README.md).

В контейнере сессия сохраняется в `/data/parser.session` на постоянном томе.
SOCKS5-прокси опционален: `TELEGRAM_PROXY_HOST` и `TELEGRAM_PROXY_PORT`.
Без `TELEGRAM_PROXY_HOST` используется прямое подключение.

Для локальной разработки из папки `parser`:

```bash
uv sync
uv run python -m src.auth
uv run python -m src.main
```

При локальном запуске задайте `RABBITMQ_URL` в окружении: адрес `127.0.0.1:5673`
и учётные данные брокера из общего `.env`. По умолчанию локальная сессия — `parser.session`.
